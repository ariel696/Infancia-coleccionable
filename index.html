Notas root para seguir trabajando

Esta información aparece solo para la cuenta administradora. Sirve como mapa rápido para futuras mejoras del sitio.

  • Firebase Auth: login con Google. La cuenta root/admin está definida en JavaScript como EMAIL_ADMIN.
  • Firestore: colección usuarios por uid, con monedas, ultimoReclamo y coleccionables.
  • Firestore: colección productos, con nombre, imagen y array opciones con id, nombre y precio.
  • Cloudinary: el admin sube imágenes de productos desde admin.html; la URL pública queda guardada en productos.imagen.
  • Páginas clave: index.html maneja sesión y monedas, tienda.html lista productos, producto.html compra opciones, coleccion.html muestra la colección y admin.html administra productos.
  • Reglas importantes: la seguridad real debe vivir en reglas de Firestore; ocultar botones en el frontend solo mejora la experiencia, no protege datos.
  • Para IA futura: mantener sincronizado EMAIL_ADMIN entre js/script.js y js/admin.js, y evitar guardar productos sin imagen.
